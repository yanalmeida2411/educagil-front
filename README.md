# Front-end do Educágil 🚀

![Badge de Status](https://img.shields.io/badge/Status-Em%20Construção-orange)

## 📌 Sobre o Projeto

O front-end da plataforma Educágil foi desenvolvido com foco em performance, acessibilidade e experiência do usuário. Utilizamos TypeScript para garantir um código robusto, seguro e escalável, e Tailwind CSS para acelerar a estilização e manter uma consistência visual entre todos os componentes.

## 🛠 Tecnologias Utilizadas

- **TypeScript**: Tipagem estática para um desenvolvimento mais seguro e confiável.
- **Tailwind CSS**: Utilização de utilitários para construção rápida de interfaces modernas e responsivas.
- **Next.js**: Framework para React, com foco em performance, rotas otimizadas e Server Side Rendering.

## 🎯 Foco da Interface

- Interfaces intuitivas tanto para **professores** quanto para **alunos**.
- Layouts responsivos, com adaptação a diferentes dispositivos e tamanhos de tela.
- Componentes reutilizáveis e modularizados, seguindo boas práticas de desenvolvimento front-end.

## 🔄 Integração com Squads

O desenvolvimento da interface foi alinhado com os times multidisciplinares do Educágil, garantindo que cada componente atenda diretamente às necessidades mapeadas pelas squads **Visão do Professor** e **Visão do Aluno**.

## 📥 Instalação

1. Clone o repositório:

```bash
   git clone https://github.com/educagil/Front-Educagil.git
```

2. Instale as dependências:
   ```bash
   npm install
   ```
3. Execute o projeto:

```bash
npm run dev
```
